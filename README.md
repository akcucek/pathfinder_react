# Pathfinder React

This project is a React application built with Vite, featuring role-based authentication and dynamic dashboards for Admin and User roles.

## Features
- Role-based login page (Admin/User)
- Role-based routing: Admin and User dashboards
- Modular page structure (Admin, User, RCA, Test Cases, User Stories, Media Upload, MCP Data Source, MCP Prompt)
- Context-based authentication (src/contexts/AuthContext.jsx)
- Centralized state management (src/store/)
- API integration examples (src/services/apiService.js)
- Sidebar navigation (src/components/Sidebar.jsx)
- Protected routes (src/components/ProtectedRoute.jsx)
- Tailwind CSS for styling

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Open your browser at `http://localhost:5173`

## Usage
- Explore additional features: RCA report generation, test case generation, user stories, media uploads, and more.

## Project Structure
- `src/pages/` - Contains all main pages and dashboards
- `src/components/` - Reusable UI components
- `src/contexts/` - Context providers (e.g., Auth)
- `src/services/` - API service layer
- `src/store/` - Redux store and slices
- `public/` - Static assets

## Customization
- Extend authentication logic in `src/contexts/AuthContext.jsx`
- Add new roles or dashboards in `src/pages/`
- Integrate APIs via `src/services/apiService.js`

## Testing
- Place test files in `src/__tests__/`
